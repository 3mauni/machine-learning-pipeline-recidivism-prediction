# Machine Learning Pipeline for Recidivism Prediction

## Overview
This project builds an end-to-end machine learning pipeline to predict 3-year recidivism risk using Python.

## Workflow
- Data preprocessing
- Exploratory data analysis
- Feature engineering
- Model training
- Model evaluation
- Explainability analysis
- Fairness assessment

## Models Used
- Logistic Regression
- Lasso
- Ridge
- Elastic Net
- Random Forest
- Gradient Boosting
- Support Vector Machine
- Neural Network

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- SHAP
- Fairlearn
- Matplotlib
- Seaborn

## Results
Gradient Boosting achieved the strongest overall performance based on precision, recall, and F1-score.

## Purpose
This project demonstrates machine learning model development, evaluation, explainability, and fairness analysis.
